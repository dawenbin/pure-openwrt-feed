pure-openwrt-feed

自建 OpenWrt apk 源 · 含 daed、vmlinux-btf 与 luci-app-daede · 不含任何凭据

使用方法

wget -O /etc/apk/keys/pure-openwrt-feed.pem   https://dawenbin.github.io/pure-openwrt-feed/keys/pure-openwrt-feed.pem
echo https://dawenbin.github.io/pure-openwrt-feed/x86_64/packages.adb   >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add daed

索引

x86_64/packages.adb · keys/pure-openwrt-feed.pem · 构建定义

每个包保留最近 3 个版本。

daed: AGPL-3.0 · daeuniverse/dae-wing
luci-app-daede: AGPL-3.0 / Apache-2.0 · kenzok8/openwrt-daede
